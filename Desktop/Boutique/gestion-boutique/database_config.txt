# CONFIGURATION BASE DE DONNÉES - GESBOU

## ÉTAPE 1 : Créer la base de données dans phpMyAdmin
1. Ouvrir XAMPP Control Panel
2. Démarrer Apache et MySQL
3. Ouvrir phpMyAdmin : http://localhost/phpmyadmin
4. Créer une nouvelle base de données : "gesbou"
5. Cliquez sur "Créer"

## ÉTAPE 2 : Configurer le fichier .env
Modifier le fichier .env avec ces informations :

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=gesbou
DB_USERNAME=root
DB_PASSWORD=

## ÉTAPE 3 : Tester la connexion
Après configuration, tester avec :
php artisan migrate:status

## ÉTAPE 4 : Créer les tables
Les migrations suivantes seront créées :
- categories
- produits  
- ventes
- detail_ventes
- utilisateurs (si nécessaire)
